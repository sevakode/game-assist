# Остаток до готового продукта

Требования подтверждены в REQUIREMENTS.md: MIT, ChatGPT+сайт, shared/self-host, без спойлеров, нейтральные напоминания. Первая практическая цель — HP/мана Belmont’s Curse; реальные флаги требуют сейвов и проверки.

## Локальная beta уже реализована
- Разрешения по играм, типизированные наблюдения, экспорт и удаление.
- Локальный интерфейс, read-only MCP JSON HTTP.
- Steam OpenID и клиент достижений с мок-тестами.
- Linux watcher с отказом на небезопасном обходе; тесты.

## Не закрыто
- Реальный пользовательский вход Steam и API acceptance с разрешённым операторским доступом.
- Библиотека Steam/выбор нескольких и всех игр с отдельным согласием.
- Windows watcher, платформенные тесты SteamOS, установщики/автозапуск/подпись.
- Фоновые обновления достижений, миграции/retention/audit для production.
- Проверенные декодеры конкретных игр и тестовые сейвы с согласием владельца.
- Источники карт/гайдов, spoiler control и доказуемые рекомендации.
- Hosted MCP OAuth/PKCE, изоляция пользователей, HTTPS deployment, live ChatGPT test.
- Завершить визуальные и прерываемые UI-сценарии.
- Независимый security review, юридические тексты, release acceptance.

Не считать создание кода подтверждением работоспособности внешних интеграций.
