# Согласованные требования — 31 октября 2026

## Продукт
- Open source под MIT, включая коммерческое использование. Лицензия приложения не перелицензирует чужие игры, изображения, гайды и зависимости.
- Основной интерфейс ChatGPT; сайт для входа, просмотра собственного прогресса и настроек.
- Общий публичный MCP с минимальными операционными расходами; собственная установка и локальные разбор/хранение также обязательны.
- Первые игры: Castlevania: Belmont’s Curse, Elden Ring, The Witcher 3.
- Цель: все достижения и помощь в прохождении без пропуска важных предметов. Поддержка должна быть доказана по каждой игре/версии, а не обещана по наличию Steam AppID.

## Сюрпризы и помощь
- Не раскрывать будущих персонажей, боссов, событий, предметов, локаций или последствий.
- Не показывать названия/описания/картинки/ID закрытых достижений; не раскрывать скрытые знаменатели прогресса.
- Уровни помощи minimal / standard / guided управляют подробностью помощи, но не разрешением на спойлеры. Это не настройка сложности самой игры.
- Guided может подробнее помогать подготовиться на основе уже известного контекста, не называя ожидающее впереди событие.
- Владелец разрешил нейтральные напоминания вроде «Не забудь осмотреться», в том числе перед необратимыми шагами. Не объяснять будущие последствия.
- Напоминание требует проверенного игрового условия. Его нельзя выдавать просто потому, что неизвестен прогресс.
- Если данных недостаточно, уточнить положение/цель у игрока; никогда не считать отсутствие достижения доказательством непройденного этапа.

## Бесшовная работа
- После одноразового входа, выбора игр и разрешений компаньон работает в фоне. Ручные токены и загрузка каждого сейва — только инструменты разработки, не финальный UX.
- Автоматический вход/доступ к облачным сейвам не обещается через один Steam OpenID. Официальный read_cloud требует отдельно выданного Valve OAuth Client ID и AppID-scopes.
- Базовый автоматический путь: Steam синхронизирует локальный сейв → локальный агент безопасно читает → отправляет разрешённую проекцию.

## Приватность
- Оригинальные сейвы только читаются, никогда не исправляются/перезаписываются.
- Парсинг может выполняться локально; в общий сервис отправляются только отдельно разрешённые структурированные сведения, не сырой сейв по умолчанию.
- Нужна возможность локального хранения и собственного сервера.
- Облачный ChatGPT получает контекст, который пользователь разрешил запросить через MCP; локальное хранение не делает саму обработку ChatGPT локальной.
- Права задаются по играм и источникам, отзыв действует сразу, будущие игры не включаются молча.

## Экономичность
- Нет обязательной LLM-модели на сервере: диалог ведёт ChatGPT.
- Изменения/хеши вместо постоянной пересылки, стабильные снимки, ограниченные версии, кэш общих публичных справочников, отдельный приватный кэш пользователя.
- Общий публичный сервис не обязан быть безлимитным. Квоты/задержки обновления должны быть видимы, а стоимость подтверждается измерениями, не обещанием нулевой цены.

## Что не было разрешено
Публикация, создание аккаунтов/ключей, изменение доступов, платное размещение, установка в чужие аккаунты или push не выполнены и не подразумеваются согласованием дизайна. Последняя рабочая инструкция — сначала локально на облачном компьютере, push позже.
