# Competitor research starting points
- Playnite: open-source local game library manager; extensible plugins, metadata aggregation. https://playnite.link/
- GOG GALAXY: multi-platform game library aggregation. https://www.gog.com/galaxy
- Exophase: achievements and trophy tracking across platforms. https://www.exophase.com/
- Steam Hunters: Steam achievement tracking and completion community. https://steamhunters.com/
- SteamDB: Steam game metadata and account tools. https://steamdb.info/
- Completionist.me: Steam achievements and completion statistics. https://completionist.me/
